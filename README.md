📘 Article Preview Card

A simple and responsive Article Preview Card built with pure HTML and CSS.

This project is a clean UI component that displays an article preview with image, category tag, publication date, title, description, and author information.

🚀 Features

- Semantic HTML5 structure

- Responsive design (mobile-friendly)

- Custom font using @font-face

- Hover effect on title

- Flexbox layout

- Clean and modern card UI

🛠 Technologies Used

- HTML5

- CSS3

- Flexbox

- Media Queries

📂 Project Structure
├── index.html
├── style.css
├── fonts/
│   └── Figtree-VariableFont_wght.ttf
└── images/
    ├── illustration-article.svg
    └── image-avatar.webp

📱 Responsive Design

- The layout adjusts for smaller screens using media queries:

- Font size adapts for mobile

- Card shadow and border change on very small screens

- Image resizes properly

🎨 Design Details

- Background Color: hsl(47, 88%, 63%)

- Card Shadow Effect

- Rounded Corners

- Hover effect on article title
